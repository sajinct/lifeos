Only selected lists and their items are saved. New lists are private and have new IDs. Names, categories, quantities, units, positions, notes, checked state and archives are preserved. Original ownership, sharing, check attribution, timestamps and other modules are omitted. Checked items are attributed to you at import time. Existing lists are not overwritten. Keep source list IDs stable on reupload; a new ID creates a new list even if its title matches. Remove template examples before importing.
